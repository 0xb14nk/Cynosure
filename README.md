# Cynosure Linux

> A hybrid distribution based on Artix, focused on maximum system control and secure working with AUR.

## Project Progress 
- [x] **`aura-emerge`**: Primary package manager (handles standard repos, AUR, and ABS inside `bwrap` sandboxes).
- [ ] **Profiles**: Fast base installation with hot-swappable init systems.
- [ ] **`ae-eselect`**: Management toolbox for `aura-emerge` and `libalpm`/`alpmDB`.
- [ ] **`ae-catalyst`**: Stage 3 builder for profile and project directories.
